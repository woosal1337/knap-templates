# Changelog

## 1.0.0 - 2026-09-13

### Features

- Add Knap template selection from configured vault folders.
- Add JSON data loading and editing.
- Add automatic Knap previews for configured template files.
- Open the rendered Knap preview from the Obsidian reading-view button.
- Add a live Markdown preview.

### Safety and support

- Add safe Markdown note creation without file replacement.
- Add active-template validation.
- Accept linked-data comments with or without a space after `input:`.
- Add desktop and mobile support.
- Update build and test tools to patched releases.

### Interface

- Align the template preview with the native Obsidian reading view.
